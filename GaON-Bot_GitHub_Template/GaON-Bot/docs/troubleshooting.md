# Troubleshooting

가온봇 제작 중 발생했던 문제와 해결 과정을 정리한 문서입니다.

## 1. ESP32-CAM 영상 끊김 문제

### 문제
모터를 구동할 때 ESP32-CAM 영상 송출이 끊기거나 불안정해지는 문제가 발생했습니다.

### 원인 추정
모터 구동 시 순간적으로 전류가 많이 필요해 전압 강하가 발생했고, 이로 인해 ESP32-CAM 전원이 불안정해졌을 가능성이 있습니다.

### 해결 방향
- ESP32-CAM 전원을 보조배터리 5V로 분리
- 모터 전원과 카메라 전원을 분리
- GND 공통 연결 확인
- 배선 접촉 불량 확인

---

## 2. LCD 표시 불안정 문제

### 문제
배터리 전압이 부족하거나 배선이 불안정할 때 LCD 표시가 깨지거나 이상하게 나오는 문제가 있었습니다.

### 해결 방향
- Arduino UNO 5V 전원 안정화
- I2C 배선 SDA/SCL 확인
- LCD GND 연결 확인
- 전원 공급 상태 확인

---

## 3. 보조배터리 자동 전원 차단 문제

### 문제
ESP32-CAM 전류 소모가 낮거나 일정 조건에서 보조배터리가 자동으로 꺼질 가능성이 있었습니다.

### 해결 방향
- 발표 전 미리 전원 유지 여부 확인
- 보조배터리 잔량 확인
- 가능한 경우 전원 버튼 접근성 확보
- 구조 내부에 배터리가 막히지 않도록 설계 개선

---

## 4. 모터 방향 반대 문제

### 문제
좌회전/우회전 또는 전진/후진 방향이 의도와 다르게 동작할 수 있습니다.

### 해결 방향
- 모터의 HIGH/LOW 방향을 코드에서 반대로 수정
- 좌우 바퀴 배선 방향 확인
- 실제 테스트 후 함수 단위로 수정

---

## 5. 배선 접촉 불량 문제

### 문제
작품 내부 배선이 흔들리거나 빠지면 영상, LCD, 모터 동작이 불안정해질 수 있습니다.

### 해결 방향
- 납땜부 확인
- 점퍼선 고정
- 전원선 굵기 확인
- 발표 전 이동 중 흔들림 방지
