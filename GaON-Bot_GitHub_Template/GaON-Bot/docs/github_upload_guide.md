# GitHub Upload Guide

이 문서는 가온봇 프로젝트를 GitHub에 올리는 방법을 설명합니다.

## 1. GitHub 저장소 만들기

1. GitHub에 로그인합니다.
2. 오른쪽 위 `+` 버튼을 누릅니다.
3. `New repository`를 선택합니다.
4. 저장소 이름을 입력합니다.

추천 이름:

```text
GaON-Bot
```

5. 공개 포트폴리오로 쓸 거면 `Public`을 선택합니다.
6. `Create repository`를 누릅니다.

## 2. 웹에서 바로 업로드하는 방법

Git 명령어가 어렵다면 이 방법이 가장 쉽습니다.

1. 만든 저장소에 들어갑니다.
2. `Add file`을 누릅니다.
3. `Upload files`를 선택합니다.
4. 이 프로젝트 폴더 안의 파일들을 드래그해서 올립니다.
5. 아래 Commit message에 다음처럼 입력합니다.

```text
Initial upload of GaON Bot project
```

6. `Commit changes`를 누릅니다.

## 3. 올리기 전에 확인할 것

- Wi-Fi 비밀번호 제거
- 학번, 전화번호 등 개인정보 제거
- 용량 큰 영상 파일 제거
- 발표자료에 개인정보가 있으면 가리기
- 코드가 컴파일되는지 확인

## 4. 시연 영상 올리는 방법

용량이 큰 영상은 GitHub에 직접 올리지 말고 다음 중 하나를 사용하세요.

- YouTube 일부공개
- Google Drive 공유 링크
- 학교 계정 드라이브 링크

그리고 `demo/demo_link.md`에 링크를 넣으면 됩니다.
